# Odin Recipes

Welcome to Odin Recipes, my first project from The Odin Project curriculum! This project demonstrates foundational HTML skills by building a basic recipe website consisting of a main index page and multiple recipe sub-pages linked together.

## 🛠️ Built With
* **HTML5:** Used semantic elements to structure the content, headings, lists, images, and anchor links.
* **Git & GitHub:** Used for version control and hosting the project repository.

## 📂 Project Structure
```text
odin-recipes/
├── index.html          # Main homepage containing links to all recipes
├── recipes/            # Folder containing individual recipe pages
│   ├── lasagna.html    # Recipe 1 page
│   ├── pizza.html      # Recipe 2 page
│   └── burger.html     # Recipe 3 page
└── images/             # Folder containing food images for the recipes


## 🎯 What I Learned

Through building this project, I practiced and solidified:

Writing clean, valid HTML5 boilerplate structure.

Using heading tags (<h1> through <h6>) to organize page hierarchy.

Creating unordered and ordered lists (<ul>, <ol>, <li>) for ingredients and cooking steps.

Using relative file paths to link separate HTML pages and display images (<a>, <img>).

Managing version control locally and pushing code updates to GitHub using terminal commands.

## 💻 How to Run Locally

If you want to view or test this project on your local machine:

Clone the repository:

Bash
git clone [https://github.com/mujeeb-mughal1/odin-recipes.git](https://github.com/mujeeb-mughal1/odin-recipes.git)

Navigate into the project folder:

Bash
cd odin-recipes
Open the project: Double-click index.html or open the folder in your favorite code editor (like VS Code) and use an extension like Live Server to view it in your browser.
